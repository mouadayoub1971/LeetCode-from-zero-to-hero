# LeetCode From Zero to Hero

Complete path to master LeetCode by **notion → pattern → problems**.

## Start here

**Open [`chapters/README.md`](./chapters/README.md)** — full roadmap (27 chapters).

### Curriculum overview

| Phase | What you learn |
|-------|----------------|
| 00–08 | Complexity, arrays/hash, two pointers, window, stack, binary search, lists, trees, tries |
| 09–16 | Heap, backtracking, graphs, DP, greedy, intervals |
| 17–25 | Math, bits, Union-Find, segment tree, design, strings, monotonic, topo, shortest path |
| 26 | Pattern recognition + interview playbook |

Each chapter has:
- Notion explained with templates
- Easy → Medium → Hard problem lists (LeetCode links)
- Exit criteria (when to move on)

## Older practice folders

Root folders (`TwoPointers/`, `DFS/`, `BFS/`, …) are earlier scratch solutions. Prefer the structured path under `chapters/`.
